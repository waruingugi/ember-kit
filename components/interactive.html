How the React parts became plain HTML

Every hook has a plain browser twin.

In ReactOn this page
useRef buffers and flagsOne state object. The loop reads it every frame, just like the refs.
useState for the readout and tooltipThe text is written straight into the page, once a second or when the pointer moves.
useEffect render loopThe same requestAnimationFrame loop. It still sleeps when the chart is off screen or the tab is hidden.
useElementWidthA ResizeObserver that redraws the grid and labels.
motion.circle pulseOne CSS @keyframes on the head dot. Calm and Off turn it off.
useReducedMotionprefers-reduced-motion plus the Lively, Calm, Off switch. Off snaps to each new reading.
Tooltip and useDismissOutsideOne placed <div>, and a tap anywhere else clears it.
buildFrame, valueAt, visibleExtentSmall rewrites. Their source files were not shared, so they follow what the chart needs.

04 Dot field

07 Scroll progress
